# Каршеринг. Лабораторная работа 1

[![CI](https://github.com/Goga211/highload-lab1/actions/workflows/ci.yml/badge.svg)](https://github.com/Goga211/highload-lab1/actions/workflows/ci.yml)

Курс «Высокопроизводительные системы», ИТМО, группа P3432.
Авторы: Долинный Михаил, Антипин Григорий.

Монолит на Spring Boot: пользователи и водительские удостоверения, парк машин и телеметрия,
наряды на обслуживание со складом запчастей, тарифы и опции, аренда от брони до завершения
с расчётом стоимости, штрафы ГИБДД с перевыставлением клиенту, счета и платежи.

## Стек

Kotlin 2.3, JDK 21, Gradle 9 (Kotlin DSL, version catalog), Spring Boot 4.1, Spring Data JPA,
PostgreSQL 16, Liquibase, springdoc OpenAPI 3 и Swagger UI, JUnit 5, MockK, Testcontainers, JaCoCo,
ktlint, Docker Compose.

Схема базы: [docs/schema.dbml](docs/schema.dbml), открывается на https://dbdiagram.io (Import → DBML).

## Запуск

```bash
docker compose up --build
```

Поднимаются `postgres` и `app`. Liquibase создаёт схему и загружает демо-данные (контекст `demo`).

- Swagger UI: http://localhost:8080/swagger-ui.html
- OpenAPI: http://localhost:8080/v3/api-docs
- Health: http://localhost:8080/actuator/health

Переменные окружения описаны в [.env.example](.env.example). Без `.env` используются значения по умолчанию.

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DB_URL`, `DB_USER`, `DB_PASSWORD` | подключение к PostgreSQL | задаёт compose |
| `RENTAL_RESERVATION_TTL_MINUTES` | время жизни брони до старта | 30 |
| `FUEL_LOW_THRESHOLD_PERCENT` | порог топлива для наряда на заправку | 15 |
| `LIQUIBASE_CONTEXTS` | `default` только схема, `default,demo` со схемой и демо-данными | `default,demo` |

## CI/CD

GitHub Actions ([.github/workflows/ci.yml](.github/workflows/ci.yml)) на каждый push и pull request:

1. `./gradlew check`: ktlint, модульные и интеграционные тесты с Testcontainers, порог покрытия 70%.
   Итоги тестов и покрытия в сводке прогона, отчёты в артефактах.
2. `docker compose up --build`: стек поднимается как на защите, проверяются health, OpenAPI и демо-данные.
3. Сборка Docker-образа. Из `main` образ публикуется в GitHub Container Registry:
   `ghcr.io/goga211/highload-lab1:latest` и тег по коммиту.

## Тесты

```bash
./gradlew check
```

Нужен запущенный Docker: интеграционные тесты поднимают PostgreSQL в Testcontainers и применяют
все миграции с нуля. `check` падает, если покрытие строк ниже 70% или код нарушает конвенции Kotlin
(ktlint, правила в `.editorconfig`, автоисправление `./gradlew ktlintFormat`). Отчёт покрытия лежит в
`build/reports/jacoco/test/html/index.html`.

Гонки из отчёта проверяются настоящими параллельными транзакциями: две брони одной машины
(`RentalFlowIT`), списание последней запчасти (`MaintenanceApiIT`), устаревшая карточка машины
против брони и телеметрии, планировщик против одновременного старта (`RaceConditionsIT`).

## Устройство

Один сервис и одна база. Код разложен по доменным пакетам, у каждого свои слои
`controller`, `dto`, `service`, `repository`, `entity`, `mapper` и свой ченджлог Liquibase:

| Пакет | Что внутри |
|---|---|
| `users` | пользователи, водительские удостоверения, проверка ВУ |
| `fleet` | модели, машины, зоны, телеметрия, наряды, склад запчастей |
| `rentals` | тарифы, опции, аренды, истечение броней, штрафы |
| `billing` | счета, журнал платежей, идемпотентные денежные операции |
| `common` | базовая сущность, ошибки RFC 9457, пагинация, конфигурация |

Пакеты общаются только через сервисы (`UserDirectory`, `FleetOperations`, `BillingOperations`),
не через репозитории соседа. Ссылки между доменами хранятся как `uuid`, внешние ключи между доменами
вынесены в отдельный ченджлог `cross-domain`. В ЛР2 каждый пакет станет отдельным сервисом.

### Транзакции

1. **Бронирование.** Машина захватывается условным `UPDATE ... WHERE status = 'AVAILABLE'`,
   аренда вставляется под частичным уникальным индексом, депозит замораживается под
   `PESSIMISTIC_WRITE` на счёте. Нехватка денег откатывает и захват машины.
2. **Завершение.** Телеметрия, зона финиша, расчёт стоимости, наряды на ТО и заправку, списание
   и возврат остатка депозита. Повторный вызов возвращает прежний результат без второго платежа.
3. **Снятие брони.** Отмена клиентом или истечение по планировщику (`FOR UPDATE SKIP LOCKED`).
4. **Перевыставление штрафа.** Поиск аренды по машине и времени, списание с клиента.

Порядок блокировок везде один: аренда, машина, наряд, склад, счёт.

### Ошибки и документация

Все ошибки, и наши, и уровня Spring MVC (нет параметра, неизвестный путь, не тот метод), приходят
в формате RFC 9457 с полями `type`, `title`, `status`, `detail`, `instance`, `errors`.
Swagger описывает для каждой операции реальный код успеха (201, 204) и возможные ошибки.

### Правила, которые легко пропустить

- Штраф оспаривается после разбора. Удовлетворённое обжалование отменяет его и возвращает деньги,
  отклонённое (`POST /fines/{id}/reject-dispute`) возвращает в REBILLED или NO_RENTAL.
- Отмена наряда возвращает списанные в него запчасти на склад.
- Модель машины меняется только у свободной машины или на обслуживании.
- Повтор `Idempotency-Key` с другой суммой пополнения даёт 422.
- Бесплатных минут брони в тарифе должно быть меньше, чем живёт бронь.

### Пагинация

Все списки принимают `page` и `size` (от 1 до 50, иначе 400).
`GET /api/v1/vehicles` отдаёт общее количество в заголовке `X-Total-Count`,
`GET /api/v1/rentals/history` работает как бесконечная прокрутка: `{content, hasNext}` без общего количества.
